# SafeRoute

## Project Goal

SafeRoute is a personal travel safety application designed to help people feel safer when traveling alone. The idea came from concerns about personal safety during transportation, especially in Vietnam. My long-term goal is to develop SafeRoute into an application that can be used by people around the world.

For this project, I will build a Java console prototype that simulates the main safety features.

## MVP Scope

The first version of SafeRoute will allow users to:

- Enter their starting location, destination, and planned route.
- Save vehicle information and emergency contacts.
- Simulate location updates and check whether the user is following the planned route.
- Display a warning when the simulated route changes unexpectedly.
- Ask users to confirm they are safe when a route deviation occurs.
- Simulate a follow-up check after 10 minutes and display an alert to trusted contacts if the user reports being unsafe or does not respond.
- Confirm safe arrival at the destination.
- Display saved emergency contact information.
- Save and view trip information using text files.

This version will not use real GPS tracking or send actual emergency notifications.

## Future Plans

In future versions, I hope to add:

- Real-time GPS tracking and interactive maps.
- Live location sharing with trusted friends and family.
- Real notifications to emergency contacts.
- Offline location storage and synchronization when an internet connection becomes available.

## Tech Stack

- **Programming Language:** Java
- **Libraries:** Scanner, ArrayList, LocalDateTime, Duration, FileReader, FileWriter
- **Development Environment:** Visual Studio Code (VS Code)
- **Version Control:** Git and GitHub
- **Data Storage:** Text files or CSV files
- **External APIs:** None for the first version

## Project Status

SafeRoute is currently in the planning and design stage. Development will follow the milestones outlined in the project design document.
